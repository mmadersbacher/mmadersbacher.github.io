00  WHAT THIS IS

Most of what I do is capture the flag — web exploitation, reverse engineering, crypto, forensics. It's the fastest way I've found to learn how a system actually works: by finding the exact place it doesn't.

When a competition ends the same instinct goes at real tools. I read the source, find the bug, and send the patch upstream. Writing my own tooling in Rust and Go is a side effect of that — not the headline.

02  WHAT FALLS OUT — PATCHES UPSTREAM

Bugs I hit while poking at the tools everyone in this field runs. Merged into the real projects, not my own repos — each links to the pull request.

Scapy #5090 merged NBNS name-query responses only returned the first address record — now every entry gets parsed. Volatility 3 #2017 merged The capabilities plugin failed on Linux kernels before 6.3 — fixed the structure handling. Volatility 3 #2016 merged An architecture typo was blocking scheduled_tasks on 32-bit memory images. Impacket #2263 merged BootpDecoder crashed on plain BOOTP packets with no DHCP options — closed the crash (#1900). Nuclei Templates #16902 merged Detection for CVE-2020-10204 (Nexus Repository Manager 3 RCE), verified against a live instance. LOLBAS #520 merged Documented Vssadmin.exe deleting shadow copies (MITRE T1490). Sigma #6238 open Detection rule for Kerberos pre-auth disabled — the precondition for AS-REP roasting.
