CVE-2026-103043 anchorme.js ≤ 3.0.8

ReDoS in the regex that pulls IPv6 hosts out of a URL, reachable through the default anchorme() call. A URL under 100 bytes makes it backtrack exponentially and the Node.js event loop just stops.

No fix released as of October 2026, npm latest is still 3.0.8. Credited under my real name on the CVE record.

CVE-2026-90776 Nodemailer 9.1.0 to 10.0.4

The address parser in lib/addressparser goes quadratic on comment-joined addresses. Through mailparser that is reachable from outside with a normal inbound mail, no auth, and the event loop stalls for seconds.

Reported through a GitHub private advisory with a PoC and a fix suggestion. The maintainer patched it in 10.0.5. Credited on the advisory and on the CVE record.

feroxbuster #1322 open If parallel came from a config file, every run died with an unwrap panic (#1321). Scapy #5150 merged · 3 Sept 2026 The BGP NLRI dissector crashed when the prefix on the wire was shorter than the mask said. Scapy #5149 merged · 3 Sept 2026 IP6ListField crashed on a truncated last IPv6 address. That field sits in about 17 dissectors, DHCPv6, ICMPv6 and SRv6 among them. Impacket #2263 merged · 2 Sept 2026 BootpDecoder threw struct.error on BOOTP messages below the 300 octets RFC 1542 requires (#1900). Now handled the way the RFC says, with regression tests. LOLBAS #520 merged · 26 Aug 2026 Entry for Vssadmin.exe deleting shadow copies (MITRE T1490). Scapy #5096 merged · 26 Aug 2026 NSH MD-Type 2 context headers didn't dissect at all, count_from had been given a string. Redone along RFC 8300 with real length handling. Scapy #5095 merged · 26 Aug 2026 OPC DA: STDOBJREF.IPID and OpcDaFack.selack used field classes where packet classes belong, so dissecting them raised TypeError. Scapy #5094 merged · 26 Aug 2026 Bluetooth Set_Extended_Advertise_Enable always returned a single advertising set, no matter what num_sets said. Volatility 3 #2017 merged · 19 Aug 2026 The capabilities plugin broke on Linux kernels before 6.3. Fixed the structure handling. Volatility 3 #2016 merged · 19 Aug 2026 An architecture typo blocked scheduled_tasks on 32-bit memory images. Scapy #5090 merged · 16 Aug 2026 NBNS name query responses only gave back the first address record. Now every entry gets parsed.
