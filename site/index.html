01 — the short version

Eighteen, and most of what I know about security I learned by building the tool instead of reading about it — then finding out where the real ones break, and patching them.

No CS degree behind me and none of this is coursework. It started with one question — how does this actually work, and where does it fall apart? — and turned into reading a lot of source, writing scanners in Rust and Go, and eventually opening pull requests against the frameworks the field itself runs on. 02 — patches to tools the field uses

Not my own repos — fixes and detections merged into the open-source projects that security teams, forensicators and pentesters actually run. Every entry links to the real pull request.

Scapysecdev/scapy merged

NBNS name-query responses only ever exposed the first address record. The parser now walks and returns every entry — so host discovery over NetBIOS stops silently dropping results.

The capabilities plugin failed outright on Linux memory images from kernels older than 6.3. Fixed the structure handling so forensic analysis works across the older kernels that are still everywhere in the field.

A single-character architecture typo was blocking the scheduled_tasks plugin on 32-bit images. Small diff, but it silently broke a whole analysis path — now fixed.

Most of what I understand came from implementing it. When a tool I want doesn't exist — or I want to know how the real one works — I write my own in Rust or Go: local network and IoT discovery, API reconnaissance for bug-bounty work, packet inspection.
